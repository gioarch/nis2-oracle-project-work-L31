# Project Work L-31 - Oracle Database e NIS2

Repository contenente il materiale sviluppato per il Project Work del corso di laurea L-31.

L'obiettivo del progetto è progettare e implementare una base dati relazionale in Oracle Database per supportare la gestione di asset, servizi, fornitori, responsabili e punti di contatto, modellando anche le dipendenze tra le diverse entità, con particolare riferimento al contesto introdotto dalla direttiva NIS2.

## Stato di avanzamento

Attualmente sono stati definiti i requisiti principali e sono in corso la progettazione del modello concettuale e logico della base dati e la realizzazione dei primi script SQL.

Il repository verrà aggiornato progressivamente con gli sviluppi del progetto e con la documentazione prodotta durante le varie fasi di lavoro.

## Tecnologie utilizzate

- Oracle Database
- SQL
- Oracle SQL Developer
- Oracle SQLcl

## Contenuti previsti

- Script di creazione dello schema database
- Dati di esempio per il collaudo
- Query SQL e viste per l'interrogazione dei dati
- Documentazione tecnica e diagrammi del modello dati
- Istruzioni per l'esecuzione del progetto
